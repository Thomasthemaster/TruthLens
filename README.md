# 🔎 TruthLens
### An application that helps you identify the truth.

An application that helps you learn how to identify false information and practice through scenarios.

---

## 🌍 The Problem

The world is filled with misinformation.

## 💡 Our Solution

We teach people how to identify misinformation.
But instead of only teaching people how to identify misinformation, we do something differently; also letting them practice identifying misinformation with made-up scenarios.

## ✨ Features

- Solutions & hints tailored to each scenario
- Rewards System (XP & Ranks)
- Multiple evidence - you must sort irrelevant evidence from useful evidence

## 🎮 How It Works

How to use TruthLens:

1. Open the application
2. Go to Detective Academy
3. Practice!
